把“看完了”变成三个判断

1 · 画出断掉的传力路径（8 分钟）在 Key Bridge 侧视图上画一条车轮到基础的路径。停在主跨开始下落前，预测哪些杆件会重新分担荷载。再解释为什么“有很多三角形”并不能直接保证失墩后仍稳定。
2 · 只改变一个量：把船速从 6.4 kn 改为 3.2 kn，记录动能比。动能比较能回答什么，为什么还不能据此确定撞击力？
3 · 为判断寻找证据：对照监控关键帧、俯视航线和既有防撞墩，写下哪些结论已经有资料支持，哪些仍需要测量或计算。
